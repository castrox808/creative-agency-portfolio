# Creative Agency Portfolio Platform

This is my React project for the school lab assignment. I built a simple single-page website to show different creative work cards.

## What the website does:
Search Box Filter: You can type letters in the search input box to find projects by title immediately.
Filter Buttons: You can click the buttons; All, Web, and Brand to sort cards by category.
Add Work Form*: You can type a new title and description in the input boxes, click save, and a new card will appear.
save memory: It uses local storage so if you add a new card and refresh the browser, your card stays on the screen.

## How to run it locally:
1. Open the folder terminal.
2. Type (npm install) to download files.
3. Type (npm run dev) to start the preview page.
